- `report.html`：基础英雄、海克斯与共同对局总览。

## 完整数据与还原

`data/matches-*.jsonl.gz` 是3485场完整原始对局，保留双方10人、海克斯字段及SQGG评分；每个分片可独立用gzip打开，按编号顺序连接解压后的内容可还原原始JSONL。`data/aram_mayhem.sqlite.gz.part*` 是同一完整SQLite数据库压缩流的顺序分片，必须先按编号连接再解压；不要把单个part当作gzip打开。分片避免超过GitHub文件限制，不损失字段。

已汇总JSON、逐局指标JSONL、CSV、9人索引、英雄与海克斯字典均直接附带。未包含重复的个人分页缓存，所有直拉对局均已进入去重后的完整数据。

安装Python 3后，在本目录执行：

```sh
python tools/restore_data.py --verify-only
python tools/restore_data.py
```

第一条逐文件校验并流式验证完整数据，无需生成约0.93GB解压副本；第二条还原到 `restored/`，已有且一致的文件跳过，不覆盖内容不同的文件。`manifest.json` 保存包内SHA-256；`data/dataset.json` 保存原始未压缩文件的SHA-256。均为Python标准库，无第三方依赖。

## 上传GitHub与Pages

1. 解压ZIP，将目录内文件上传仓库根目录，包括隐藏文件`.nojekyll`、`.gitignore`，保留目录结构。不要仅上传ZIP作为网页站点。
2. 每个包内文件小于25MiB，可分批通过GitHub网页上传，也可用Git或GitHub Desktop提交。ZIP本身用于附件/Release，勿把还原后的数据库或JSONL提交仓库。
3. 需要网页时，在仓库 Settings → Pages 选择从分支发布，选择相应分支和根目录。是否可用取决于账号方案及仓库可见性。
4. 如果只需要分享下载，将ZIP作为Release附件；收件人离线打开index.html。

GitHub限制说明：https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github

## 数据口径与边界

最早开局2025-10-24 20:12:32，最晚2026-09-19 12:49:32（北京）。九人分页均到空页；这不等于完整历史。山本直拉988场经共同对局补到1650场，祈山鹤984场补到1334场。对局以平台和match_id去重，玩家统计以(match_key,puuid)去重。同局不同朋友分别计一次出场，英雄汇总不直接平均个人胜率。

K头=平均队内击杀占比/平均队内对英雄伤害占比；承伤占比为逐局个人承伤/完整己方五人承伤，再取均值。缺失不补零。SQGG评分不是官方熟练度。低胜率分组、天使carry分组都是透明的人为分析规则。五排口径为九人内五人同队，已由用户确认预组；不含带名单外朋友的五排。

完整记录含游戏ID、PUUID、队友和对手游戏内名称，公开仓库会公开这些记录。本包没有登录令牌、Cookie、账号密码、浏览器日志、客户端采集器或个人电脑路径。此次仅整理本地分发包，没有替用户上传或发布。
